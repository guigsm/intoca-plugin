# Palavras do proprietário dadas na Diretoria

Aqui ficam os "vai", os "pode" e as decisões que o proprietário dá no chat da Diretoria sobre um projeto
(regra 4 do regimento). Um arquivo por palavra, a partir de `diretoria/modelos/palavra.md`,
com o nome `<AAAA-MM-DD>-<ID>.md`.

- Quem grava: só a Diretoria, com as palavras exatas, a data e a hora de Brasília.
- Quem lê: o gerente do projeto, antes de agir. Vale o arquivo, não a mensagem entre chats.
- Produção e ato sem volta: a Diretoria repete antes o que entendeu e só grava com a confirmação.
- A autorização de produção do projeto continua sendo gravada pelo gerente, citando o arquivo daqui.
- A palavra dada no chat do próprio gerente continua valendo como sempre; não precisa de arquivo aqui.
