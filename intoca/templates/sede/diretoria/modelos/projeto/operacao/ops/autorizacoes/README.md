# Autorizações do projeto

Produção só com autorização registrada em arquivo. O arquivo que vale é
`<projeto>/ops/autorizacoes/<ID>.md` (o quê, limites, data, quem autorizou), gravado pelo Gerente depois do "pode" do proprietário no chat deles. A OS cita esse arquivo;
sem ele, o executor para. Esta pasta guarda no máximo notas de apoio e nunca substitui o arquivo do projeto.
